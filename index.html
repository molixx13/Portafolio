Sobre mí

Soy un desarrollador frontend de Colombia enfocado en la creación de sitios web robustos con JavaScript y CSS. Cuento con experiencia práctica aplicando tecnologías modernas como React y Angular para garantizar velocidad, interactividad y una buena experiencia de usuario.

Mi perfil se complementa con el manejo de análisis de datos usando Python y PHP, bases de datos SQL y NoSQL, y herramientas esenciales como Docker y Git.

Proyectos

AutoGestión — Concesionario

Sistema de gestión para concesionarios de vehículos desarrollado con Django. Permite administrar inventario, ventas y registros del negocio desde una plataforma web centralizada.

Servicio Orquestador

Servicio en Python encargado de orquestar y coordinar la comunicación entre distintos procesos, gestionando el flujo de datos de forma centralizada.

Reloj Pomodoro

Widget de reloj Pomodoro totalmente configurable a gusto del usuario, pensado para gestionar el tiempo y mejorar la concentración durante el trabajo.

Tutorial — Juego de Cartas

Proyecto web interactivo que recrea un juego de cartas, aplicando manipulación del DOM, lógica de juego y diseño de interfaz con tecnologías frontend.

Actividad de Escalamiento

Proyecto académico enfocado en conceptos de escalamiento y arquitectura de aplicaciones, explorando buenas prácticas para el crecimiento de sistemas.
