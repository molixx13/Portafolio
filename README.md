# Portafolio — Kevin Esteban Molina Gaitán

Portafolio personal de **Kevin Esteban Molina Gaitán**, desarrollador frontend de Colombia.

Sitio estático (HTML, CSS y JavaScript) con tema oscuro y tipografía serif, que presenta una breve biografía, los proyectos públicos, las tecnologías manejadas y la información de contacto.

## Estructura

```
portfolio/
├── index.html          # Estructura y contenido
├── styles.css          # Estilos (tema oscuro, responsive)
├── script.js           # Año dinámico + botones de copiar contacto
├── assets/             # Foto de perfil
└── images projects/    # Capturas de cada proyecto
```

## Ejecutar localmente

Basta con abrir `index.html` en el navegador.

## Tecnologías

HTML · CSS · JavaScript · React · Angular · Python · PHP · Django · MySQL · MongoDB · Git · Docker
